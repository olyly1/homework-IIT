# Отчёт по практической работе №7 (Git)

## Шаг 1. Установка Git
Проверила, установлен ли Git, командой `git --version`. Git установлен.
Указала имя и почту командами `git config --global user.name` и `git config --global user.email`.

## Шаг 2. Создание локального репозитория
Создала папку командой `mkdir ~/homework-IIT` и перешла в неё командой `cd`.
Инициализировала репозиторий командой `git init -b main`.
Проверила состояние командой `git status`.

## Шаг 3. Первый коммит
Создала файл отчёта report.md в репозитории.
Добавила его в индекс командой `git add report.md`.
Зафиксировала версию командой `git commit -m "Первая версия отчета: шаги 1 и 2"`.
Посмотрела историю командой `git log --oneline`.

## Шаг 4. Ветка отчёта
Создала ветку командой `git switch -c report-branch`.
Дописала в отчёт описание шагов 3 и 4.
Зафиксировала изменения в новой ветке.

## Шаг 5. Слияние веток
Перешла в основную ветку командой `git switch main`.
Слила изменения из ветки отчёта командой `git merge report-branch`.
Проверила результат командой `git log --oneline`.
